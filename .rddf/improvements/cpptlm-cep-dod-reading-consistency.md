## 架构依据

**C4 = 治理线 G6「DoD 读法一致」的落地**。两项 MUST-FIX 都源自 **Entry #332 ⑧**（architect 裁决 + oracle PASS-WITH-NOTES + critic REJECT 的返工项），其共同根因是**同一件事有两套读法**，而**没有一处载体同时承载两者**。

| MUST-FIX | 契约依据（逐字可核） | 要消除的读法分叉 |
|---|---|---|
| **MUST-FIX-1** | `Entry #332 ⑧`：「口径 ④ 须显式声明「**Stage 4+ 准入 = `§4.5` 的实质条件（队列 #14 完成），`§4.6` 的 `2030-Q1` 为派生值、已失去现行性**」」；⚠️ Entry #332 ① 的措辞纪律 = 必须写「**追认**已进入」，⛔ **否掉「提前进入」** | 现状 = **日历**（`2030-Q1`）当准入条件;实测 = 队列 #14 已于 2026-11-04 完成 ⇒ **实质准入早已满足**，而日历值仍写在 `§4.5` 标题 + `§4.6` 三行 ⇒ 读法分叉 |
| **MUST-FIX-2** | `Entry #332 ⑧`：「⛔ **只重裁 `07 号:1262` 一处是不够的** —— 实施轮会因此把互相矛盾的两条禁令冻进 M1 冻结件」+ 三处清单 + 验收判据「三者缺一 ⇒ 口径 ④ 仍会僵住」 | 现状 = 禁令的**作用域**只说「⛔ 不得整行改写为已达成」;而登记格式（B2 同型「✅ **N/4**（N 有引擎 + M 授权⏭，逐族机器可查 + 逐族触发条件 + 台账锚）」）在 N ≥ 1 时**必然含「✅」** ⇒ 字面撞该禁令 ⇒ **读法分叉**（同一禁令既禁 N=0 形态又禁 N≥1 的合法分解形态） |

⇒ C4 **不碰**任何 DoD 计数（B3b-2 仍 **0/4**）、**不碰**分母、**不新建 ADR** ⇒ 它是**纯读法订正**：把「同一禁令的两个作用域」在**唯一权威载体**上唯一化（**1 处声明 + 2 处指针**，⛔ 禁复写），并把 Stage 4+ 准入从日历改为事件。

**⚠️ 隐藏目标（per metis ①）**：本 change 的真正价值不止「读法一致」，还有 **防静默删除** —— `07 号` 收口批（Entry #333/#339）已把全部判据正文迁成指针 ⇒ 若禁令继续只活在台账/手册，下一次结构重构就可能把它删掉而**无任何闸看得见** ⇒ 故权威声明必须落进**冻结件**（`07 号` 新 SU），并由闸守住。

## Why

**两处读法分叉都还开着，而 C3 刚把「有登记、无牙齿」这条治理线闭合** ⇒ C4 若仍以**文档登记**收尾，就会**再制造一处「有登记、无牙齿」**。

| 缺口 | 实测（可复核） | 不修的后果 |
|---|---|---|
| **MUST-FIX-1 的日历依赖** | `obj §4.5` 标题含 `2030-Q1`;`§4.6` 三行含 `2030-Q1`;而 `§4.0` 队列表第 14 行 = `cpptlm-cep-ualink-inc` ✅ **两段式均已完成归档**(2026-11-04) | 读者按**日历**读准入 ⇒ **准入早已满足却读成未满足** ⇒ `§8.3` 归档前置被日历误锁（**Entry #332 ①** 已判「Stage 4+ 未进入**不是真实状态**」) |
| **MUST-FIX-2 的作用域二义** | `docs/guide/cep-usage.md:162` = 「⛔ **不得**把 B3b-2 整行改写为「已达成」」;而登记格式（B2 同型「✅ **N/4**（N 有引擎 + M 授权⏭，逐族机器可查 + 逐族触发条件 + 台账锚）」）在 N ≥ 1 时**必然含「✅」** ⇒ 字面撞该禁令 | N = 1 之日**无人可裁** ⇒ 终态 DoD Go **永久僵住**（= Entry #332 ⑧ 自陈的后果）;⛔ 而**今日 N = 0** ⇒ 现在**不宣称达成**的禁令**仍然有效** ⇒ 重裁**只改作用域、不放松今天** |
| **权威载体已随治理批迁出** | `07 号` 现行版内「自欺 / 整行改写 / 宣称达成」**0 命中**;`07 号:520` 仍写「④ 对 DoD 的影响(**五选项 甲~戊**)→ **`Entry #249` ⑤**」⇒ **丁仍是活载体**(经指针链),⛔ 非化石 | 若不重定位 ⇒ 重裁会落到**无人读的镜像**上;若把丁当化石 ⇒ 「三处重裁」实为两处 ⇒ **判据被悄悄删一条** |
| **指针悬空** | `docs/guide/cep-usage.md:162` 的「⛔ **本条最终口径以「口径 ④ 本体新 SU」(Entry #332 ⑪ 落点)为准**」⇒ 该 SU **从未落地**（口径 ④ **未 ratify**） | 手册**指向不存在的东西** ⇒ 读者按指针找不到口径 ⇒ 反而**制造新的读法不一致** |
| **C3 刚落地的治理教训** | C3 把 R-c / R-d 落成**机器判据**（16/16 自测）⇒ 治理线其余条目若停在文档层,**判据强度断层** | C4 成为 G6 的**唯一无牙条目** ⇒ 与 C3 同标准不一致 |

**⛔ 不可约残余（必须落进 design.md 的诚实边界）**

1. 重裁**只解除**「N ≥ 1 的分解形态」与绝对禁令的冲突，⛔ **不放松**任何今天生效的禁令（N = 0 时一律 ⏭、永不 ✅）;
2. 闸只验「**文本形态 + 出现次数 + 指针目标存在**」，⛔ **不验**「读者是否真按该读法理解」;
3. 「恰 1 命中」只保证**唯一性**，⛔ 不保证**正确性**（错的句子若唯一也绿）⇒ 故须与**逐字文本可核**（AC-2/3/4）**并用**;
4. **长期维护税**:手册第 3 条自此**受 CI 锁定** ⇒ 今后任何正当编辑该行都须同步闸内常量 ⇒ 成本已计入 Impact。
