# scripts/test/cep_adr_exclude.txt —— CEP ADR 清单的**显式排除集**
#
# 用途（登记册 G-16）：`scripts/test/cep_docs_sync_check.sh` 的 `ADR_LIST` 是
#   **正向**覆盖集（清单 → 磁盘：存在 + 含「不变量/决策」节）。
#   本文件是它的**反向**对偶：磁盘 `docs/adr/ADR-CEP-*.md` 全量 ⇒ 每一份
#   都必须落在「`ADR_LIST` ∪ 本排除集」之内 ⇒ **新增 ADR 忘登记即判红**。
#
# 格式（每行一条）：
#   <文件名>|<理由>
#   · 文件名 = `docs/adr/` 下的文件名（含 `.md`）
#   · 理由 = **非空**；缺理由 ⇒ 判红（纸面排除 = 无声脱检）
#   · 文件必须**在磁盘上真实存在**（防「预先排除一个未来才出现的文件」⇒ 提前挖洞）
#   · 文件**不得**同时在 `ADR_LIST` 里（那会让排除变成多余登记 ⇒ 判红）
#
# ⚠️ **当前为空**：实测磁盘 24 份 `ADR-CEP-*.md` 与 `ADR_LIST` 24 条**逐名相等**
#    ⇒ 无需排除。新增排除必须写明理由（⛔ 不得留空行/注释当排除项）。
#
# 影子模式（决定性变异用，⛔ 不改真实清单）：
#   CEP_ADR_EXCLUDE_FILE=<影子文件> bash scripts/test/cep_docs_sync_check.sh --strict
